# Carte du ciel fr/en/es — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** La carte du ciel s'affiche en français, anglais ou espagnol selon `?lang=` passé par l'app.

**Architecture:** Un module pur `i18n.js` porte toutes les tables et formateurs ; `app.js` crée une locale au démarrage depuis l'URL et l'utilise partout (translateFn, labels HTML, boussole, tracé, pont RN). Les noms de constellations viennent d'un `index.json` de skyculture par langue, généré par script et servi par `server.js`. L'app RN ajoute `?lang=` à l'URL de la WebView et renvoie l'état d'affichage au `ready`.

**Tech Stack:** JS navigateur sans build, Node 20 (`node --test`), React Native / Expo (Jest).

**Spec:** `docs/superpowers/specs/2026-09-26-skymap-i18n-design.md`

## Global Constraints

- Langues : `fr`, `en`, `es` ; absente/inconnue → `fr`.
- Le rendu français actuel ne change pas (tables FR déplacées sans modification).
- Aucune dépendance, aucune étape de build dans `stellarium/`.
- Modules navigateur au motif `;(function (global) { ... global.X = api; if (typeof module !== 'undefined' && module.exports) module.exports = api; })(typeof globalThis !== 'undefined' ? globalThis : this);`
- Anglais : noms anglais courants des constellations (champ `english` upstream) ; `Polaris` reste `Polaris`.
- Heures du tracé : fr `22h` / `03h12`, en `10 PM` / `3:12 AM`, es `22:00` / `03:12`.
- Commentaires et messages de commit en français, fin de commit `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Langue régionale ou casse** (`en-US`, `ES`, `es_419`) → doit donner `en` / `es`, pas `fr`. Test dans Task 1.
2. **Nom localisé qui coïncide entre deux clés** (fr : `Moon` → `Lune` dans NAMES et ENGINE_UI ; `Sculptor` en → `Sculptor`) → `toEngineName` doit rendre une clé moteur valide, jamais planter. Test d'aller-retour dans Task 1.
3. **Heure 0 et midi en anglais** → `12 AM` / `12 PM`, pas `0 PM`. Test dans Task 1.
4. **Traversée de chemin** (`/skycultures/v3/western-fr/../../../etc/passwd`) → jamais servie en local. Test dans Task 4.
5. **Rechargement de la WebView** (changement de langue, bouton « Réessayer ») → `readyRef` repasse à faux, et l'état d'affichage (constellations masquées, pollution, décalage temporel, gyro) est réappliqué au `ready`. Vérification manuelle dans Task 6.

```js
// Génère les skycultures traduites : node scripts/build-skyculture-i18n.js [chemin/upstream.json]
// Sans argument, télécharge l'index upstream. Seul common_name.native est
// réécrit : c'est le nom que le moteur dessine.
'use strict';
const fs = require('fs');
const https = require('https');
const path = require('path');
const { CONSTELLATION_NAMES, SUPPORTED } = require('../i18n.js');

const UPSTREAM = 'https://stellarium.sfo2.cdn.digitaloceanspaces.com/skycultures/v3/western/index.json';
const OUT_DIR = path.join(__dirname, '..', 'data-overrides/skycultures/v3/western');

function buildSkyculture(upstream, lang) {
    const names = CONSTELLATION_NAMES[lang];
    return {
        ...upstream,
        constellations: upstream.constellations.map(c => {
            if (!names[c.iau]) throw new Error(`Constellation sans nom ${lang} : ${c.iau}`);
            return { ...c, common_name: { ...c.common_name, native: names[c.iau] } };
        }),
    };
}

function fetchJson(url) {
    return new Promise((resolve, reject) => {
        https.get(url, res => {
            if (res.statusCode !== 200) return reject(new Error(`HTTP ${res.statusCode} ${url}`));
            let body = '';
            res.setEncoding('utf8');
            res.on('data', d => { body += d; });
            res.on('end', () => { try { resolve(JSON.parse(body)); } catch (e) { reject(e); } });
        }).on('error', reject);
    });
}

async function main() {
    const src = process.argv[2];
    const upstream = src ? JSON.parse(fs.readFileSync(src, 'utf8')) : await fetchJson(UPSTREAM);
    for (const lang of SUPPORTED) {
        const file = path.join(OUT_DIR, `index.${lang}.json`);
        fs.writeFileSync(file, JSON.stringify(buildSkyculture(upstream, lang)));
        console.log('écrit', path.relative(process.cwd(), file));
    }
}

module.exports = { buildSkyculture };
if (require.main === module) main().catch(e => { console.error(e); process.exit(1); });
```

```js
const SKYCULTURE_I18N = /^\/skycultures\/v3\/western-(fr|en|es)\/(.*)$/;

// Décide si un chemin /data/* est servi depuis data-overrides/ ou proxifié.
// La skyculture traduite vit à une URL par langue (western-<lang>) : son
// index.json est local, ses illustrations viennent de western/ upstream.
function resolveDataPath(upstreamPath) {
    const pathOnly = upstreamPath.split('?')[0];
    if (path.posix.normalize(pathOnly) !== pathOnly) return { upstream: upstreamPath };
    const m = SKYCULTURE_I18N.exec(pathOnly);
    if (m) {
        if (m[2] === 'index.json') {
            return { local: path.join(OVERRIDE_DIR, 'skycultures/v3/western', `index.${m[1]}.json`) };
        }
        return { upstream: '/skycultures/v3/western/' + m[2] };
    }
    const overridePath = path.join(OVERRIDE_DIR, pathOnly);
    if (overridePath.startsWith(OVERRIDE_DIR + path.sep)) {
        try {
            if (fs.statSync(overridePath).isFile()) return { local: overridePath };
        } catch (_) { /* pas d'override */ }
    }
    return { upstream: upstreamPath };
}
```

```ts
/**
 * URL de la carte du ciel avec la langue de l'app (`?lang=`). La WebView la
 * lit au chargement ; changer de langue change l'URL, donc recharge la carte.
 */
export function buildStellariumUrl(base: string | undefined, lang: string): string | undefined {
  if (!base) return undefined;
  return `${base.replace(/\/+$/, '')}/?lang=${encodeURIComponent(lang)}`;
}

/** Vrai pour le document principal de la carte, query string comprise. */
export function isStellariumDocument(url: string, base: string): boolean {
  const path = url.split(/[?#]/)[0].replace(/\/+$/, '');
  return path === base.replace(/\/+$/, '');
}
```
